## Por que este repositório existe

Aqui guardo pequenos projetos em Python feitos para praticar fundamentos:
manipulação de arrays, estruturas de dados e lógica básica, incluindo um
mini banco de dados via terminal.
```
Hoje uma IA gera esse tipo de código em segundos, e eu escrevo à mão de
propósito. Sem entender o que está sendo construído, não dá para revisar,
depurar nem saber se o caminho escolhido é o melhor. A IA também não
conhece as regras de negócio de cada contexto, e cabe a quem programa
verificar se elas foram aplicadas corretamente. Este repo é meu treino para
manter esse julgamento afiado e usar a IA como ferramenta, não como muleta.
```
